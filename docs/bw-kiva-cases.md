# BW・KIVAの追加評価

## 実験時集計

両モデルのZero-shotは初回6/15、10回以内7/15。
BWは8件が上限到達、KIVAは5件が上限到達・3件がMTSA処理未完了。
試行別の終了理由とログは [試行索引](trial-index.md) を参照する。

BWは敗北領域内にMixed Stateがないため候補生成できず、KIVAは69,318件の候補を
生成したものの介入・再合成を完了できなかった。失敗理由を区別する。

## BWの成功に分類された7試行の変更

保存コードの静的確認では次の違いがあった。

| 試行 | 保存コードにおける変更 |
|---|---|
| 6・8・14 | 既存のassign[Team]を制御可能に変更 |
| 10・11・13 | assignを制御不可能のまま維持し、新たなgrant/permitAssignを前置 |
| 15 | 新たな機構に加え、assign[Team]も制御可能に変更 |

したがって、7件すべてを新規許可のみの修正とは扱わない。
10・11・13のような事例は、Mixed Stateに基づく候補生成の対象外でも、
モデル上に新たな制御機会を設ける修正が可能であることを示す。
ただし、既存モデル上に制御機会のない段階では、その実行主体・機構も新たに検討する必要がある。
Mixed Stateの場合も、既存の制御可能事象が環境事象を実際に抑止できるとは限らない。
どちらも具体機構の実現可能性、遷移不能回避、必要動作の維持は別途検証を要する。
本公開整理ではBW・KIVAの新たなMTSA再合成や必要動作検査は行っていない。

KIVAのZero-shot成功も、本手法が探索を完了できなかったモデルに対してLLM単独の
修正が合成に到達したという結果であり、修正の妥当性や実現可能性を保証するものではない。
合成成功と設計の適否の区別は他のモデル・条件にも共通する。
