# Meaning of the Additional Control Record

Each entry has the following meaning:

- State:
  A game state where an additional control point should be considered.

- Action:
  An uncontrollable action that should be preceded by an additional controllable action in the environment model.

- Available ControllableActions:
  A list of controllable actions that the target uncontrollable action should synchronize with.
  The new controllable action to be inserted before the Action should mediate this synchronization.
  In other words, design the new controllable action as a synchronization, permission, confirmation, or suppression point that connects the target uncontrollable action with the listed controllable actions.

# Repair policy

1. Modify the environment model so that the uncontrollable action shown in each Action field is preceded by a new controllable action.

2. Use the Additional Control Record as guidance. The goal is not to invent an entirely new model, but to concretize the suggested additional control points in the given environment model.

3. Preserve the original safety requirements. Do not weaken, remove, or rewrite the safety monitors to make synthesis easier.

4. Preserve the original model structure, process names, action names, parameters, and branching structure as much as possible.

5. Add new controllable actions only where they are needed to realize the Additional Control Record.

6. Do not change the meaning of existing uncontrollable actions. The repair should introduce additional controllable synchronization or permission points before them.

7. Output the complete revised DCS model and a concise explanation of the changes.
